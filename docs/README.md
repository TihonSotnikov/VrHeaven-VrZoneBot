# Исторические документы

Эти два документа — вход в работу по приведению бота в боевое состояние
(август 2026). Они описывают систему **до** переделки: аудит нашёл дефекты,
план предложил архитектуру. Обе задачи выполнены, поэтому читать их стоит
как историю решений, а не как описание текущего поведения.

Что система делает сейчас — [SPEC.md](../SPEC.md); как устроен код —
[README.md](../README.md); как её эксплуатировать —
[deploy/RUNBOOK.md](../deploy/RUNBOOK.md).

- [AUDIT.md](AUDIT.md) — аудит готовности к эксплуатации.
- [PRODUCTION_REMEDIATION_PLAN.md](PRODUCTION_REMEDIATION_PLAN.md) — план работ.
